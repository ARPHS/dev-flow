# Debug

采用以下循环：

```text
失败样例 → 最小复现 → 假设 → 观测 → 修复 → 回归验证
```

先保存真实失败输入、环境、命令、退出码和完整输出。把问题缩小到最小可复现路径，区分代码、数据、环境和基线因素。每个假设都配一个能证伪它的观测，不在没有证据时连续猜测。

修复根因并加入不会只匹配当前实现的回归测试或等价检查。性能问题记录相同条件下的前后指标。验证失败时回到证据和假设，不通过放宽断言、删除测试、吞掉错误或绕过真实入口来让结果变绿。连续三轮没有新证据时保留现场并报告具体阻碍。
