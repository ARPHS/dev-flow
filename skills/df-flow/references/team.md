# 协作与交付

默认不调用子代理。只有任务可以清晰拆成相互独立的行为、并行节省时间，或需要与实现者分离的审查时才分工。协调成本高于并行收益时由当前 agent 完成。

实现代理只修改指定工作区，不提交、不推送、不写主控状态。交付报告必须包含修改文件、验证命令、退出码、验收证据、已有改动和阻碍。主控必须亲自检查 diff 并运行验证，不能只接受报告。

审查代理只读代码和文档，不修改业务代码或台账。审查对象必须绑定基线、当前提交、任务或规格版本。报告按 Critical、Important、Minor 分级，给出位置、原因、影响和验证依据。

外部交付只有在版本、分支、基线、回执和实际验证一致后才能集成。集成后重新运行受影响验证，再更新任务状态。任何代理无法启动、停止或回调时都要如实说明，不假称后台监听。
